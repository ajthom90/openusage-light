# Dashboard

The menu-bar panel shows one card for each account added in Settings → Accounts. A card displays the limits and dollar values returned by that provider's API.

When no accounts have been added, the panel shows **Add Account** and opens Settings → Accounts.

Use **Customize** to choose which account metrics are visible, move them between Always Visible and On Demand, and change their order. Accounts are independent: each has its own card, layout, and cached provider response.

OpenUsage Light does not read local usage logs, estimate spend from model pricing, or discover accounts from other apps.
