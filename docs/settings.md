# Settings

Settings is inside the menu-bar panel.

## Accounts

Use **Add Account** to choose a provider and sign in with OAuth or enter an API key. Add multiple accounts for the same provider, rename them, or remove them. Removing an account also removes its credential from the app's Keychain service.

## General

**Launch at Login** controls whether the app starts when you sign in to macOS. **Global Shortcut** records a keyboard shortcut that toggles the panel.

## Appearance

Choose the menu-bar icon style, app theme, panel density, and time format.

## Notifications

Enable alerts for low remaining usage and changes in quota pace. macOS notification permission is requested when an alert is first enabled.
